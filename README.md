# Dosan Jung1 English Real Test (Sep 2026)

Interactive practice quiz for **2026학년도 2학기 1차시험 1학년 영어 (도산중학교)** — built for Mr. Jay’s students.

## Live site

**https://mrjkorea.github.io/dosan-jung1-english-realtest-sep2026/**

Open the link, answer all 12 items, then click **제출하기 (채점)** for scoring, sample answers, and short explanations.

## Local preview

```bash
cd /path/to/repo
python3 -m http.server 8080
```

Visit `http://localhost:8080/`.
