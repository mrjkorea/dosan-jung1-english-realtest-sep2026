# Dosan Jung1 English Real Test (Sep 2026)

Interactive practice quiz for **2026학년도 2학기 1차시험 1학년 영어 (도산중학교)** — built for Mr. Jay’s students.

## Live site

**https://mrjkorea.github.io/dosan-jung1-english-realtest-sep2026/**

Open the link, answer all 12 items, then click **제출하기 (채점)** for scoring, sample answers, and short explanations.

## Local preview

```bash
cd /path/to/repo
python3 -m http.server 8080
```

Visit `http://localhost:8080/`.

## Contents

- `index.html` — exam layout (all 12 questions)
- `css/style.css` — mobile-friendly styles
- `js/scoring.js`, `js/app.js` — answer checking
- `assets/` — map, poster, mountains, Alaska brochure crops from the scanned exam pages

## GitHub Pages (one-time setup)

Code is on `main` with a **Deploy GitHub Pages** workflow (`.github/workflows/pages.yml`). The cloud agent token could not enable Pages via `gh api` (403). If the live URL returns 404:

1. Open **Settings → Pages** on the repo.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Re-run the latest **Deploy GitHub Pages** workflow (or push any commit to `main`).

The site URL will be: **https://mrjkorea.github.io/dosan-jung1-english-realtest-sep2026/**
